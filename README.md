## Work

**[Tide Island](https://github.com/enhaoswen/Tide-island)**

A Dynamic Island for Hyprland, and the one that started all of this. It has a lot in it, and I spent most of my time on how it looks: the shapes, the spacing, the way each panel opens and closes into the next. It isn't the lightest thing you'll run. It was trying to be the one you leave on your desktop because it looks right.

**[Tide Island New](https://github.com/enhaoswen/Tide-Island-New)**

The rewrite, still in development. It looks the same as the original, but uses far less memory and CPU.
